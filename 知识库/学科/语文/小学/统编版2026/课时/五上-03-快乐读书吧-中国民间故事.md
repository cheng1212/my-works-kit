# 五年级上册 第三单元 · 快乐读书吧“从前有座山”·《中国民间故事》整本书阅读（导读 / 推进 / 分享）

## 内容

### 一、定位
- 第三单元末栏目，教材第49–50页；单元前接 8 猎人海力布、9 牛郎织女（一）、10* 牛郎织女（二）、口语交际 讲民间故事、习作 故事新编、语文园地 [1]。
- 单元导语原文：“民间故事，口耳相传的经典，老百姓智慧的结晶。”“阅读民间故事，感受其中蕴含的朴素愿望和真挚情感。”语文要素：“了解故事内容，并创造性复述”“按照自己的想法新编故事” [1]。
- 课时：教材**不规定**整本书阅读的课时与课型；课标要求“宜集中使用每学期整本书阅读课时” [2]。导读—推进—分享三段式是教研通行做法（见下“三”），非教材规定。

### 二、快乐读书吧原文（第49–50页，PDF 文字层 + 页面图像核对）[1]
- 标题：快乐读书吧　从前有座山
- 导语：“从前有座山，山里有座庙，庙里有个老和尚在给小和尚讲故事。讲的是什么故事呢？从前有座山……　在你很小的时候，爷爷奶奶也许就给你讲过这个故事。像这样耳熟能详的民间故事还有很多，我们一起找来读一读吧。”
- 你读过吗：“《田螺姑娘》《梁山伯与祝英台》《八仙过海》……它们都是我国民间故事中的经典篇目。人们将对美好生活的期盼，化成了一个个民间故事。你讲，我听；我讲，他听。就这样口耳相传，直到今天仍旧吸引着我们。”
- 片段：《田螺姑娘》节选（“从前，有个年轻人，独自种着几亩田过活……老太太说：‘一定是田螺姑娘帮了你的忙。’”），其后：“以上是中国民间故事《田螺姑娘》的片段。阅读我国的民间故事，你不仅能领略动人的情节，还能认识许多精彩的人物，如机智的徐文长、聪慧的巧姑。”
- 小贴士①：“作为一种口头艺术，民间故事一般有特定的主题类型和重复的段落，这是为了方便讲述者记忆，同时加深听众的印象。”
- 小贴士②：“民间故事往往寄托着人们朴素的愿望：正义却弱小的主人公有可能打败强大的对手；心地善良的穷苦人通过努力可以丰衣足食，过上幸福的生活……”
- 相信你可以读更多：“民间故事存在于世界上的每一个角落。欧洲各国的民间故事精彩纷呈。你可以跟随小牧羊人，踏上寻找三只会唱歌的苹果的旅途；你可以听到伊凡与灰额猫、山羊、绵羊在聊天；你还可以看到狡猾又幽默的列那狐是如何捉弄其他动物的……在遥远的非洲大地，大家会在闲暇的时候，让一个人领唱优美的故事，听众则伴以合唱。鳄鱼幻想着晒太阳就能长出翅膀，大象被人类逼迫着逃离家乡却仍然坚持回乡……让我们一起阅读这些故事，感受世界各地的别样风情。”
- **推荐书目**：教材本页**没有写书名**，只列篇目与中国 / 欧洲 / 非洲三个地区。教学中通用的《中国民间故事》《欧洲民间故事》《非洲民间故事》是教师据此选定的读本，不是教材原文。人教社出版“快乐读书吧”配套丛书（曹文轩、陈先云主编）[7]，其中《中国民间故事》的篇目、页码**未核验**；各班所用版本可能不同（本作品文件夹里的推进课 PPT 就用的是《田螺姑娘——中国民间故事精选》）。

### 三、知识要点
1. **民间故事的特点**
   - 教材口径（A）[1]：口耳相传（“你讲，我听；我讲，他听”）；“特定的主题类型和重复的段落”，目的是“方便讲述者记忆，同时加深听众的印象”；“寄托着人们朴素的愿望”；语文园地补充：常有“不可思议的情节”，“语言都比较口语化”，反映“对美满家庭的期待，对安居乐业的渴望”。
   - 学术口径（B，转引）：民间文学具有“口头性、集体性、类型性、变异性等特征”[8]；钟敬文主编《民间文学概论》列基本特征为集体性、口头性、变异性、传承性，并把民间故事分为幻想故事、生活故事、民间寓言、民间笑话 [9]；百科词条“中国民间故事”：幻想故事“情节常采用‘三段结构法’；人物、情节、语言基本定型”，生活故事“人物性格单纯，常常运用对比的手法。有时也采用三段结构法”[10]。（[8][10] 为百科内容的网站镜像，原书页码未核 → 🟡）
   - 课堂用语提示：“三段式／三叠式／两坏一好”是教研常用说法，**教材原文只说“重复的段落”**；不要求学生掌握术语，更不能把“三段式”理解成“必须出现数字三”。
2. **课型**（B，仅读到摘要）：
   - 推进课：“在整本书阅读的推进过程中，为了促使学生深入阅读和理解而设计并实施的教学活动……旨在通过教师的引导，使学生能够解决已发现的问题，并在与他人的交流中发现阅读的魅力，呵护阅读兴趣，延续阅读热情，明晰阅读方向，起到承前启后的作用。”[11]
   - 交流课：“在一本书阅读结束时，组织学生进行讨论、交流、分享各自理解和感受的课型。”[11]（同期专题）
   - 导读课：“应具有激发阅读兴趣、习得阅读方法的功能。”[11]（同期专题）
   - 北师大李煜晖、郑国民的小学模式用“导读课、体验课、讨论课”命名，讨论课“围绕体验课上学生共同关心的话题、议题或疑难问题，组织学生发表见解”[12]（B）——课型名称各家不同，功能相近。
3. **学生常见困难**（推进阶段）
   - B 级通述：长时间按计划阅读“容易产生阅读疲劳”[11]。
   - 本作品推进课预学单归纳的三类：读完就忘；情节相似、兴趣下降、坚持不了打卡；只能讲情节、说不出道理（来源：作品内教学设计，C 级，未见原始数据）。
   - 本库推断（待课堂验证）：把人物品质贴成标签、脱离情节；把神话、传说、寓言、作家童话都当成“民间故事”；不同学生进度差距大。
4. **与课标的对应** [2]：第三学段【阅读与鉴赏】6“阅读整本书，把握文本的主要内容，积极向同学推荐并说明理由”；文学阅读与创意表达(3)“复述印象深刻的故事情节……尝试富有创意地表达”；整本书阅读教学提示(2)“以学生自主阅读活动为主……关注整体与局部、局部与局部之间的关系；重视序言、目录”，(4)“注意考察阅读整本书的全过程……制作阅读反思单”。课标第三学段学习内容未点名民间故事。

### 五、一句话主线（推进课《寻访故事里的中国智慧》）
读到一半的困惑先摆出来，再用“析人物—品情节（重复的段落）—悟智慧（朴素的愿望）”三把钥匙回到书里重读四个故事，最后带着方法读完全书。

### 六、作品现有设计的核对结果（供第 2 步修改）
1. 逐字稿与教学设计说“回顾课本中的四篇民间故事”“课内的四个故事”：**不准确**。新版教材里《田螺姑娘》只有片段（第49页），《八仙过海》只在“你读过吗”提到书名，《一幅壮锦》只在语文园地提到书名，《鲁班学艺》教材未出现 [1]。应改为“书中的四个故事”，并核对所用版本《中国民间故事》是否收录这四篇。
2. 单元导语引语“民间故事，口耳相传的经典，老百姓智慧的结晶。”与教材原文一致 [1]。
3. “三段式”的结论可保留，但要回扣教材原话“特定的主题类型和重复的段落……方便讲述者记忆，同时加深听众的印象”[1]。
4. 新版习作是“故事新编”（不是旧版“缩写故事”），设计里的“八仙参加运动会”创编正好衔接新版习作 [1]。
5. 用 AI 小助手有课标依据（教学提示(3)“借助信息技术为学生拓展学习空间”）[2]，但课标同时强调“以学生自主阅读活动为主”“保证学生在课堂上有时间阅读整本书”，AI 环节不宜挤占读原文的时间 [2]。
