# 七年级上册 第一单元 1《春》（朱自清）

## 内容

### 一、定位
- 第一单元·阅读·第1课，教材第2–4页；第5页“读读写写”与补白《比喻》；第18页“阅读综合实践”一、二直接以本课语句为例 [1]。
- 课时：**2课时**。国家平台人教社官方课程设“春（第1课时）”“春（第2课时）”[2]（单源 A；C 级教学设计多为 2 课时 [5]）。
  - 第1课时（官方）：目标“朗读课文，边读边想象文中描绘的情景，领略优美的春日图景”“比较体会运用重音和停连的效果……”；活动：为喜欢的画面取名（句式“这是一幅____图，我似乎看见/听见/想到____。”），读链接材料，变换重音读“像母亲的手抚摸着你”，小组标注互评 [2]。
  - 第2课时（官方）：目标“揣摩品味语言及比喻修辞的表达效果，体会本文的语言之美”“运用比喻及其他修辞手法，描绘家乡美景，表达自己的情思”；活动：梳理结构、改句对比春花图、默读补白“比喻”、仿第8～10段写比喻句、写家乡美景 [2]。

### 二、单元导语要点（原文）[1]
“学习本单元，要重视朗读，在朗读中感受语言的美。要把握好重音和停连，体会声韵和节奏；边读边想象文中描绘的画面，领略景物之美；注意揣摩和品味语言，体会比喻和拟人等修辞手法的表达效果。”

### 三、课文与注释
- 课文全文（10 段，2024 版原文）与全部注释原文见作品 `05-春-初中语文PPT/01-学习笔记/学习笔记_春.md` 附录 A 与 L2 第5条（一处存，不复制）[1]。
- 易错异文：教材作“宛转”“与轻风流水应和着”“他生长着”“各做各的一份事去”“披着蓑，戴着笠的”；旧版/他本异文（“跟轻风流水应和着”“它生长着”“一份儿事”等）不得使用 [1][6]。
- 作者（注释①原文）：朱自清（1898—1948），字佩弦，江苏扬州人，散文家、诗人、学者。著有诗文集《踪迹》，散文集《背影》《欧游杂记》《你我》等。选自《朱自清全集》第四卷（江苏教育出版社1996年版），略有改动 [1]。
- 写作/发表年份：未查到 A 级来源，C 级说法不一 → **不使用**。

### 四、思考·探究·积累（原文要点）[1]
一 描绘了哪些春日图景，最喜欢哪一幅；二 “富有童趣，又带有诗的韵味，清新，活泼，优美”，找段落品味；三 理解“刚落地的娃娃”“小姑娘”“健壮的青年”三个比喻并另写比喻句；四 朗读四句注意重音停连、说加点词效果（盼望着…／小草偷偷地…／野花遍地是…／看，像牛毛…）；五 背诵全文。

### 五、朗读知识（链接材料原文）[1]
- 重音：“为传情达意的需要，对语句中的某些词或短语通过重读的形式加以强调。一般用‘.’标示在词语下面。如：山朗润起来了，水涨起来了，太阳的脸红起来了。”
- 停连：停顿“｜”（较短）“∧”（较长），连接“⌒”；“无论停顿还是连接，都不是任意的，要与文章思想感情的发展变化相适应”；例：“坐着，∧躺着，∧打两个滚，⌒踢几脚球，⌒赛几趟跑，⌒捉几回迷藏。”

### 六、知识要点与易错
1. 结构：盼春（1）—绘春（2–7）—赞春（8–10）（教学通行分法，C 级多源一致；官方设计要求“梳理课文结构”但未给出原文划分）(待核验)
2. 五幅图景：春草图、春花图、春风图、春雨图、迎春图（名称为通行命名，教材要求学生自行取名）(待核验)
3. 比喻：明喻／暗喻／借喻（补白原文）[1]；“一切都像刚睡醒的样子，欣欣然张开了眼”是拟人不是比喻（官方第2课时作业考此辨析）[2]
4. 结尾三比喻：新、美、力（C 级通行解读，作开放参考）[7] (待核验)
5. 易错字音：酝酿 yùnniàng、窠 kē、黄晕 yùn（教材注音）；应和 hè、嘹亮 liáo、抖擞 sǒu、水涨 zhǎng、撑 chēng（通行注音）

### 七、课例（L5）
- 国家平台官方课程，授课 王瑞芳（中学语文教研员、高级教师），指导 王彤彦、张晓毓（北京教育科学研究院中学语文教研室）[2]（A/B）
- 刘秀银（河北省黄骅市教师发展中心）“着”“了”品读；常福胜“反常表达”；牛玉峰（安徽临泉）诗文联想 [8] (待核验：载体 C 级，原刊出处未查到)

### 八、一句话主线
读出春的声韵（重音停连）→看见春的画面（五幅图）→品出春的语言（钻、闹、笼与比喻）→写出自己的春景（比喻练笔）。
