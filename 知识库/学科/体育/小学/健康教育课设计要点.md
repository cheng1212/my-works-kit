# 小学体育与健康 · 健康教育课（室内课）设计要点

> 本课《情绪识别与调控》是健康教育课（室内课），不是运动技能课。两种课型的设计逻辑不同，照搬技能课的套路是常见病。

## 一、课型区分

| 维度 | 运动技能课（室外） | 健康教育课（室内，如本课） |
|---|---|---|
| 主要手段 | 身体练习 | 讲解、讨论、体验、练习（小剂量身体活动） |
| 课堂结构 | 开始／准备／基本／结束四段式 | 导入／新知探究／巩固／小结（同一般室内课） |
| 核心矛盾 | 技能从不会到会 | 观念从不知到行（知信行） |
| 适用模式 | 学、练、赛、评一体化 | KAP 知信行＋体验式 |

## 二、2022 版课标中与本课直接相关的要求

1. **健康第一**是首要理念；体育与健康是"以身体练习为主要手段"的课程——即使室内课，也要有身体参与，不能上成纯讲授的心理课。
2. **核心素养三维度**：运动能力、健康行为、体育品德。本课主攻"健康行为"（心理健康领域），兼顾"体育品德"（合理表达、不伤害他人）。
3. **课程内容五大部分**：基本运动技能、体能、健康教育、专项运动技能、跨学科主题学习。本课属于"健康教育"中的心理健康。
4. **教会、勤练、常赛**：健康教育课的"练"是技能操练（深呼吸、表达句式），"赛"可转化为小组展示、互评。
5. **学业质量是核心素养的行为表现**：目标里的"能说出、能判断、能演示"就是学业质量的课堂版。
6. **评价要综合**：过程性＋终结性，教师评＋学生自评互评；健康教育课多用表现性评价（说出做法、演示出来）。

## 三、SEL 映射（CASEL 五大能力）

- 自我意识（识别情绪）→ 本课目标 1
- 自我管理（调节情绪）→ 本课目标 3
- 社会意识、人际关系技巧 → 本课目标 2 的一部分（情绪影响人际交往）＋P15 合作学习"合理表达"
- 负责任的决定 → P15 探究学习"选用一种方法"（为自己的选择负责）
写教案时可在"设计意图"里点出 SEL 对应，评审能看出理论站位。

## 四、KAP 知信行：健康教育课的行为改变逻辑

健康教育课的终极目标不是"知道"，是"做到"。KAP 三段：
- **知（Knowledge）**：识别情绪、四种基本表现——对应目标 1
- **信（Attitude）**：相信"情绪可以调控""调控对我有好处"——对应目标 2（懂得影响）。这一段最容易被跳过，但没有"信"，学生不会去"行"。
- **行（Practice）**：当场练深呼吸、当场做一分钟运动、课后用一次——对应目标 3
自查：教案里"信"的环节有没有？（讲清"为什么学这个"就是在立"信"。）

## 五、身体练习为主要手段，在室内课怎么落

课标这句话是体育课的"身份证"，室内课不能丢。落法：
1. 技能必须当场练（深呼吸两轮、一分钟运动），不能只讲。
2. 用身体做"实验"（心情温度计前后对比），让身体成为教具。
3. 课后作业必须是身体行动（运动一次、练一次深呼吸），不能只是"写一写"。
4. 实在没有大运动量，也要有"动"的环节——评审看的是"有没有"，不是"有多少"。

## 六、体育与心理健康融合（育体＋育心）

- 双重目标：每节课的目标里既要有身体/技能目标，也要有心理目标，不能只有心理。
- 挫折体验是天然素材：体育活动自带输赢、累、怕——本课 P11 小明"接不到球"就是现成的挫折情境。
- 即时引导：运动后立刻问"现在心情怎么样"，把身体感受和情绪命名连起来，这是体育课独有的心理教育时机，别课没有。

## 七、本课型常见病

- [ ] 上成心理课：40 分钟零身体活动，体育身份丢失
- [ ] 上成语文课：满堂问答，没有体验和练习
- [ ] "信"缺失：直接教方法，不讲"为什么有用"
- [ ] 评价只有"很好请坐"：没有针对目标的表现性评价
- [ ] 隐喻／游戏喧宾夺主：学生记住游戏规则，记不住知识
- [ ] 小剧场失控：表演时间吃掉练习时间
