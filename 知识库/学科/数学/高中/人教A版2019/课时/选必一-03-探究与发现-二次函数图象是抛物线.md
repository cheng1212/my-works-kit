# 选择性必修第一册 · 第三章 3.3 · 探究与发现 为什么二次函数y=ax²+bx+c的图象是抛物线

## 内容
### 位置 [1][2]
- 第三章 圆锥曲线的方程 → 3.3 抛物线 → 3.3.1 抛物线及其标准方程 → 练习（第133页）之后的“探究与发现”栏目，下接 3.3.2 抛物线的简单几何性质。
- 栏目是阅读材料，不是习题，不占独立课时；做成微课或探究课时一般 10–15 分钟。

### 教材原文要点（第133页）[1]
> 因此，只要能说明二次函数的图象符合抛物线的几何特征，就解决了为什么二次函数y=ax²+bx+c的图象是抛物线的问题。由抛物线与其方程之间的关系可知，如果能用适当的方式将y=ax²+bx+c转化为抛物线标准方程的形式，那么就可以说明二次函数y=ax²+bx+c的图象是抛物线。
- 正文只走配方＋平移一条路：y=a(x+b/2a)²+(4ac−b²)/4a；沿向量 m=(b/2a, −(4ac−b²)/4a) 平移，“除了位置外，函数图象不发生任何变化”；得 y=ax² 即 x²=(1/a)y，“顶点为原点，焦点为(0,1/4a)的抛物线”。
- 图1：y=ax² 与 y=ax²+bx+c 同框，标顶点 P(−b/2a,(4ac−b²)/4a) 和向量 m。
- 教材用字为“图象”。

### 知识与易错 [1][3]
- 一般焦点 F(−b/2a,(4ac−b²+1)/4a)，准线 y=(4ac−b²−1)/4a（自行推导核对）。
- 易错：把 y=ax² 的 a 当成 p 或 2p；p、p/2、2p 混用；平移方向判反；定义法只证一半（未说明逆向）。
