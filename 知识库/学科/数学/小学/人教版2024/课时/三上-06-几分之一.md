# 三年级上册 第六单元 分数的初步认识 · 几分之一

## 一、课题定位
- 教材：人教版（2024）小学数学三年级上册 第六单元《分数的初步认识》 第1课时“几分之一”
- 地位：单元起始课。从整数到分数是数概念的一次扩展；几分之一既是分数，也是分数单位，是后续学习几分之几、分数大小比较、同分母分数加减的基础。

## 二、课标依据（《义务教育数学课程标准（2022年版）》）
- 第二学段（3~4年级）学段目标：认识自然数，经历小数和分数的形成过程，初步认识小数和分数……形成数感、运算能力和初步的推理意识。
- 内容要求：结合具体情境，初步认识分数，感悟分数单位。
- 学业要求：能结合具体情境初步认识分数，能读、写分数；能比较两个同分母分数的大小。

## 三、知识要点
1. 平均分是分数产生的前提：只有把一个物体（图形）平均分，每份才能用分数表示。
2. 几分之一的含义：把一个物体（图形）平均分成几份，每份就是它的几分之一。
3. 读写：1/2 读作二分之一；书写顺序——先写分数线（表示平均分），再写分母（平均分的份数），最后写分子（取的份数）。
4. 各部分名称：分数线、分母、分子。
5. 拓展：形状不同、折法不同，只要是平均分成4份取1份，都是1/4（为几分之几和单位“1”做铺垫）。
6. 几分之一比大小（本课只作直观感知，不展开）：同一物体，平均分的份数越多，每份越小，1/2 > 1/4。

## 四、学情与易错点
- 学生会“平均分”，生活中熟悉“一半”，但不知道一半能用数表示。
- 易错1：没有平均分也写成分数（大小不等的两块说成各是1/2）。
- 易错2：分子分母写反、书写顺序错。
- 易错3：只数涂色部分，不看总份数。

## 五、教学线索（同课题优秀课例提炼）
- 主情境：中秋分月饼。4块→2块→1块，前两次能用整数表示，第三次“一半”无法用整数表示 → 产生新数。
- 关键反例：把1个月饼分成大小不一的2块，能用1/2表示吗？→ 强调“平均分”。
- 操作活动：用正方形纸折出1/4，比较不同折法，追问“形状不同为什么都是1/4”。
- 练习：判断能否用分数表示 → 看图写分数 → 涂色表示分数 → 生活中找分数。

## 六、本课教学主线（一句话）
分月饼遇到“一半” → 平均分产生 1/2 → 迁移到 1/4、1/3…… → 归纳“平均分成几份，每份是它的几分之一” → 读写与名称 → 练习巩固。
