# 调研规范

调研只针对库里没有或待核验的内容。每次调研必须满足以下标准，达不到不能入库。

## 一、来源分级

| 级别 | 来源 | 可以用来 |
|---|---|---|
| A 官方 | 教育部发布的课程标准原文；人教社教材、教师用书；国家中小学智慧教育平台 | 课标条文、教材内容、概念定义、单元课时安排 |
| B 权威教研 | 省市区教研室资料；“一师一优课”部级/省级优课；教育类核心期刊 | 课例、教法、学情与易错点、写法范例 |
| C 一般资料 | 学科网、教习网、21世纪教育网、教师个人博客、公众号 | 只作参考和灵感 |

## 二、硬性要求

1. **课标、教材、定义必须 A 级。** 课标条文逐字摘录，标明学段和条目位置。
2. **关键事实双源核验**：单元位置、课时划分、公式、数据，至少两个独立来源一致；只有一个 A 级来源时注明“单源”。
3. **C 级不能作唯一依据。** 只有 C 级来源的结论，标“待核验”。
4. **写法范例至少 3 篇**，其中至少 1 篇 B 级以上，提炼共性结构后再写。
5. **不凭记忆写**：课标原文、教材页码、例题必须查到原文；查不到就写“未查到”，不编。
6. **每条记录来源**：名称、链接、访问日期、级别。
7. **版本对齐**：确认教材版本年份（如人教版 2024 修订版），旧版资料不得冒充新版。

## 三、调研步骤（固定六步，只做缺口部分）

| 步骤 | 内容 | 最低来源 |
|---|---|---|
| L1 课标 | 内容要求、学业要求、教学提示 | A |
| L2 教材 | 单元位置、例题、做一做、练习、插图情境 | A |
| L3 知识 | 定义、前后衔接、易错点、考法 | A + B |
| L4 写法 | 各类文本的结构与亮点（≥3 篇范例） | B + C |
| L5 课例 | 情境、问题链、活动、难点突破 | B |
| L6 自测 | 一句话主线；重难点及突破；易错点；课标要求程度；各文本必含部分 | — |

## 四、入库标准

- 按 `条目模板.md` 填写完整，头部信息不缺项。
- 每条结论能对应到来源。
- 状态如实标注：**已核验**（A 级 + 双源/官方原文）、**待核验**（来源不足）、**已过期**（版本已更新）。
- 更新 `索引.md`。
