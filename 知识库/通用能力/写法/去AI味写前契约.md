> 移植来源：novel-library-v2 `库/成文/卡片/写作工艺-反AI指标契约.md`（“检测标准＝写作契约：动笔时是契约，收稿时是判据”）。

> 数值守恒：本卡的数必须与 `工具/去AI味/规则.json` 一致；改阈值两处一起改。跑 `python3 工具/去AI味/去AI味检查.py --契约` 可打印当前规则里的数核对。

## 一、一票否决（写出来就不能交）

- 聊天残留：`以下是一份…`、`希望对你有所帮助`、`根据您的要求` 之类
- 开场套话：`值得注意的是`、`不难发现`、`在…的浪潮中`、`开启…之旅`、`一场…的盛宴`
- 点破句式：`恍然大悟`、`说到底`
- 「」和“”同篇混用；繁体字；docx 里出现 `**`、`#`

## 二、密度红线

| 项 | 线 | 写的时候怎么避 |
|---|---|---|
| 教学空话（赋能、全方位、深度融合、充分调动、至关重要…） | ≤3 / 千字 | 写学生做什么、做到什么程度 |
| 总结腔（总之、由此可见、这说明…） | ≤1.5 / 千字 | 结论写一次，不在段尾再总结 |
| 「不是A，而是B」 | 每篇 ≤1 | 直接说是什么 |
| 三并列排比 | ≤2 / 千字 | 三个词里留最准的那个 |
| 破折号（正文） | ≤1 / 千字 | 用逗号、冒号；连线题、对应表不算 |
| 比喻词（仿佛、宛如、如同…） | ≤2 / 千字 | 类比讲一个就讲透 |
| 空泛表扬（逐字稿：非常好！你真聪明！） | 每篇 ≤3 | 点评答案本身 |
| 句长 CV | ≥0.30 | 要求用短句，过程可以长 |
| 加粗（md） | ≤8 / 千字 | 只加真正的重点 |

## 三、语义层（机器判不了，写的时候自己守）

对应 v2 的“每段要么推线索要么给人物，两样都不占就删”，教学文案版是：**每句话要么告诉老师怎么做，要么告诉学生做什么、做到什么样，两样都不占就删。**

1. **目标可观察**：动词用“说出、画出、找出、完成、比较”，不用“认识价值、养成习惯、提升素养”作唯一表述。
2. **学情写这一班**：写这节课具体会卡在哪（例如把路由器和交换机混为一谈），不写“好奇心强、抽象思维正在形成”这类放在哪课都成立的话。
3. **预设学生的错**：教学过程至少写 1–2 处学生可能的错答或卡壳，以及老师怎么接。
4. **设计意图不套模板**：不要每格都是“用……，落实/突破/渗透……”；写这一步为什么放在这里、换掉会怎样。
5. **不凑数字排比**：“一个目标、两类要素、三种方式、三大功能”式的数字串，内容本来就是这样可以留，为了好听凑出来的删掉。
6. **课标、教材原文用 > 引用**，原样照抄，不润色。
