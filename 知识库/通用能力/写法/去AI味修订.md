# 去AI味修订（教学文案版）

> 状态：可用｜类型：通用能力·写法｜适用：教案、说课稿、课堂逐字稿、学案、分层作业、评价设计、教学反思、PPT 大纲
> 移植来源：novel-library-v2 `库/成文/卡片/写作工艺-AI 稿修订专项.md`（方法论：先扫后改、逐处手术、隔轮复扫）、`程序/工具/禁忌.py`、`程序/工具/指纹.py`（机械判据）。
> 配套工具：`工具/去AI味/去AI味检查.py`，词表阈值在 `工具/去AI味/规则.json`。
> 本卡只改写法，不改内容：课标原文、教材原话、数据一律不动（`>` 引用行工具不查）。

## 一、目标与边界

去AI味的目标是**写得具体、像这位老师在这间教室里会说的话**，不是骗过检测器。

不是什么：
- 不是把文字洗成没有特征的流水账；
- 不是故意加错字、口头禅、语气词（刻意粗糙也是一种模板）；
- 不是整篇重写：重写等于再过一遍生成器，原来的毛病会回来。逐处改。

## 二、教学文案里 AI 味最重的 8 类毛病与修法

| # | 病型 | 长什么样 | 修法 |
|---|---|---|---|
| 1 | 聊天残留（HARD） | `以下是一份……教案`、`希望对你有所帮助` | 整句删掉。 |
| 2 | 开场套话（HARD） | `在信息化的浪潮中`、`值得注意的是`、`开启……之旅` | 删掉，直接从事实或任务开头。 |
| 3 | 空话动词 | “全方位提升”“深度融合”“充分调动积极性”“赋能” | 换成**学生做什么、做到什么程度**：“每组用设备卡拼出 3 个场景的连接图，并说出理由”。 |
| 4 | 总结腔 | 段尾必有“总之”“由此可见”“这说明” | 结论已在上文就删；要收束就收在下一步动作上（“接着进入任务二”）。 |
| 5 | 对举与排比 | “不是A，而是B”连用；三个四字短语一排 | 一篇最多留 1 处对举；三连排比留最准的一个词。 |
| 6 | 逐字稿太完美 | 学生句句答对，老师句句“非常好！你真聪明！” | 写出学生的典型错答和老师的追问；表扬点到答案本身（“你注意到交换机在机柜里，这个观察很准”）。 |
| 7 | 句子一样长 | 每句 20 字上下，节奏催眠 | 长短交替：关键要求用短句，过程描述可以长。 |
| 8 | 格式过度 | 每段都加粗、每条都冒号小标题、破折号成串 | 加粗只留真正的重点；破折号改逗号或冒号，表格里的对应关系除外。 |

## 三、做法（先扫后改，逐处手术）

1. **先扫**：写完文案跑 `python3 工具/去AI味/去AI味检查.py <作品文件夹>`，拿到问题清单（行号＋摘句）。
2. **分级**：✗（HARD）必须改；!（WARN）逐条人判，合理的保留（例如表格里“计算机 —— 寄件人”的破折号）。
3. **逐处改**：按清单定位，一处一处改，不整段重写；改的时候问自己“这句话只能出现在这节课里吗”。
4. **复扫**：改完重跑一次，✗ 清零才能进下一步；新冒出来的问题说明改法是换汤不换药，换个写法。
5. **朗读抽检**：逐字稿挑 2 段读出来，读着别扭的地方就是 AI 味还在的地方。

## 四、判定线

| 项 | 线 |
|---|---|
| 聊天残留、开场套话、引号混用、繁体字、docx 里的 Markdown 符号 | 0 处（HARD） |
| 教学空话 | ≤3 / 千字 |
| 总结腔 | ≤1.5 / 千字 |
| 「不是A而是B」 | 每篇 ≤1 |
| 三并列排比 | ≤2 / 千字 |
| 破折号（正文） | ≤1 / 千字 |
| 空泛表扬（逐字稿） | 每篇 ≤3 |
| 句长 CV | ≥0.30（30 句以上才判） |

教学空话、空泛表扬、句长 CV 三项是为教学文案新定的经验值，用几份真实稿后按需在 `规则.json` 里调。

## 五、自检（是/否）

1. 跑过工具，HARD 为 0？
2. 每条 WARN 都看过，留下的有理由？
3. 教学目标和活动写的是学生的可观察行为，而不是“提升、培养、激发”？
4. 逐字稿里至少有一处学生错答或卡壳，以及老师怎么接？
5. 课标、教材原文没有被“润色”？
6. 改完复扫过？
