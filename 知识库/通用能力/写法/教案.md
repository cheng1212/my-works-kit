# 教案（教学设计）写法

## 标准结构
1. 基本信息：课题、教材版本与章节、年级、课时、课型
2. 课标要求（原文摘录）
3. 教材分析：本课位置、前后联系、编排思路
4. 学情分析：已有基础、认知障碍、应对策略
5. 教学目标：按核心素养维度写，用可检测动词（能判断、能说明、能画出）
6. 教学重点与难点
7. 教法学法与教学准备
8. 教学过程：分环节，每环节写 时长 / 教师活动 / 学生活动 / 设计意图
9. 板书设计
10. 作业设计（分层）
11. 教学反思（课后填写）

## 要点
- 目标、活动、评价一一对应（教、学、评一致）。
- 每个环节都要有设计意图，说明它在突破哪个重难点。

## 理论模型（专家工具箱，2026-10-12 补）

### 1. 加涅九大教学事件（Gagné）
课堂流程的"体检表"，九个事件按顺序是：引起注意 → 告知目标 → 刺激回忆旧知 → 呈现新内容 → 提供学习指导 → 引出行为（练习）→ 提供反馈 → 评估行为 → 促进保持与迁移。用途：写完教学过程后逐项打勾，缺哪项补哪项。最常缺的是第 2 项（开课不亮目标，学生不知道这节课要干成什么）和第 9 项（下课就散，没有迁移到真实生活）。

### 2. 布鲁姆修订版二维框架（Anderson & Krathwohl, 2001）
目标陈述＝动词（认知过程）＋名词（知识类型）。认知过程六级：记忆 → 理解 → 应用 → 分析 → 评价 → 创造；知识四类：事实性、概念性、程序性、元认知。用途：检查目标动词是否可检测（"了解""体会"不可检测，"说出""判断""演示"可检测）；一节课的目标应跨 2–3 个层级，不能全停在"记忆"。

### 3. UbD 逆向设计（Wiggins & McTighe）
与传统顺序（定目标→想活动→再想怎么评）反过来，三阶段：①确定预期结果 → ②确定评估证据（什么算学会了）→ ③设计学习体验。警惕"双罪"：以活动为中心（activities-based，热闹但不知道学到了什么）、以覆盖为中心（coverage-based，赶进度讲完教材）。理解有六个侧面：能解释、能阐明、能应用、能洞察、能神入、能自知——目标 3"在帮小明情景中选用一种说出做法"对应的是"应用"侧面。

### 4. 5E 教学模式（BSCS）
引入（Engage）→ 探究（Explore）→ 解释（Explain）→ 迁移（Elaborate）→ 评价（Evaluate）。与加涅的区别：5E 以学生探究为中心，教师后退一步。适用于有"发现"空间的课；纯技能操练课不必硬套。

### 5. 教学评一体化＋GRASPS 真实任务
"教—学—评"一致：目标里写"能做什么"，活动中就练什么，评价就看什么，三者用同一动词。GRASPS 用于设计终极表现任务：目标（Goal）→ 角色（Role）→ 受众（Audience）→ 情境（Situation）→ 作品（Performance）→ 标准（Standards）。"帮小明出主意"就是一个微型 GRASPS：角色＝小明的朋友，受众＝小明，作品＝具体做法，标准＝"说出跟他说什么、陪他做什么"。

## 评审视角：好教案的 5 条硬标准
1. 目标可检测：动词＋名词，一个目标只讲一件事。
2. 活动为目标服务：每个环节的设计意图能说清"它在突破哪个重难点"，说不清的环节砍掉。
3. 有评估证据：UbD 第二阶段不能空——课堂上用什么看见"学会了"（举手判断、温度计前后对比、小组方案展示都是证据，要写明）。
4. 有迁移：知识必须落到真实生活（作业、当堂练习），否则就是"覆盖罪"。
5. 学科本体不丢：形式再花哨，学科的核心特征要在（体育课要有身体练习，语文课要有语言实践）。

## 常见病自查清单
- [ ] 目标动词不可检测（了解、体会、感受、提高……）
- [ ] 导入与目标无关（故事很热闹，但跟本课目标没关系）
- [ ] 活动只有形式没有产出（讨论了，但没要求拿出什么）
- [ ] 评价只有"很好，请坐"（没有针对目标的反馈）
- [ ] 隐喻／情境喧宾夺主（学生记住了游戏，记不住知识）
- [ ] 时间分配头重脚轻（导入 10 分钟，练习 2 分钟）
- [ ] 板书是提纲复制（板书应是本课知识结构的可视化，不是目录）

## 新发现（来自范例1，官方模板）
- 表头“课程基本信息”：学科、年级、学期、课题（含第几课时）、教科书（书名、出版社、出版日期）。
- 依次为：教学目标 → 教学重点 → 教学难点 → 教学过程（表格：教学环节／主要师生活动，环节为“导入新课—新知探究—课堂小结—课后任务”）。
- 目标用行为式表述：“朗读课文，边读边想象……领略……”“比较体会运用……的效果”。
- 语文课多课时：每课时单独一份设计，第2课时以上节课作业展示导入。

## 新发现（2026-10-11，07-纸魔方，人教教参 + 湖南集备大赛平台）
- 人教版初中教参“教学设计”固定五段：内容及其解析 → 目标及其解析 → 教学问题分析 → 教学支持条件分析 → 教学过程设计（A 级，七上教参第 376 页起）。
- 教参的教学过程每步写：问题 n／师生活动／追问／设计意图；不写教师话术，不写“预设学生回答”（拓展环节可列“预设 1/2/3”作为探究方向）。
- 湖南省集体备课大赛平台的“教学过程（必填）”栏：每个环节标时长（如 5′）＋环节名，下写 问题／师生活动／设计意图（用户团队第一稿截图）。大赛同时要求教学设计、课堂实录、课件三者一致。
