# 整本书阅读课（导读课 / 推进课 / 分享交流课）写法

> 与 `教案.md` 配合使用：教案的通用 11 部分照旧，本页只补“整本书阅读课”特有的部分。

## 一、三种课型的分工
| 课型 | 放在什么时候 | 主要任务 | 依据 |
|---|---|---|---|
| 导读课 | 开读前 | 激发兴趣、习得方法（看封面目录序言、试读一个片段）、订阅读计划 | [1] 导读课篇；课标教学提示(1)(2) |
| 推进课 | 读到中途（常见“读完一半”） | 解决已发现的问题，交流中“呵护阅读兴趣，延续阅读热情，明晰阅读方向，起到承前启后的作用” | [1] 推进课篇 |
| 分享 / 交流课 | 读完全书 | 讨论、交流、分享理解和感受；提炼方法，导向自主阅读同类书 | [1] 交流课篇；[2] 讨论课 |
- 课标依据：整本书阅读“应以学生自主阅读活动为主”，“注意考察阅读整本书的全过程”，可“制作阅读反思单”（见 `学科/语文/小学/课标.md`）。

## 二、推进课教学设计的共性结构（由下列范例提炼）
1. **反馈进度与困惑**（5–8 分钟）：用预学单 / 阅读记录的真实数据开场，挑出 2–3 个共性问题，定下本课任务。[3][5][6]
2. **范例共读，习得一个方法**：选一个点（人物 / 情节结构 / 人物关系），用一两篇做示范，配表格或图（人物档案、关系图、情节梳理表）。[3][5][6]
3. **小组迁移**：把方法用到另外几篇，任务单分工，教师巡视点拨，小组汇报时追问“为什么”。[5][6]
4. **深化**：比较、追问或思辨（如“只写一次行不行”“放到今天还有价值吗”），或创编片段。[5][6]
5. **收束与延学**：归纳方法（几把“钥匙”），分层延学任务（基础必做 + 提升 / 挑战选做），激励机制，预告分享课。[3][5]
- 目标写法：第一条常写“汇报前期阅读 + 借助读书工具梳理……”，第二条写“通过交流……感受人物 / 情节特点”，第三条写“……激发继续阅读的兴趣”。[3]
- 推进课不等于讲完全书：只抓一两个点，留下没读的部分让学生自己读。

## 三、推进课常见病（自查用，本库归纳）
- 只查进度、不教方法；或方法讲了，没给学生在书里练的时间。
- 范例篇目说成“课文”（快乐读书吧多数只给片段或书名）。
- 结论先于发现：教师直接宣布“三段式”“人物品质”，学生没有从文本里找证据。
- 道理脱离情节，变成贴标签。
- 信息技术 / AI 环节挤占读原文时间。
