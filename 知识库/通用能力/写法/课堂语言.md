# 课堂语言（教师课堂话语）

> 用途：写 PPT 备注、教案“教师活动”、说课稿里的教师原话时对照；审课件时逐页按下面的检查表过一遍。

## 内容

### 一、分哪几类
- 常用分法：导入语、讲解语（讲授）、提问语、指令语、过渡语、评价语（反馈）、结束语 [1][2][4]。
- 课堂观察编码一般并成 4 大类：讲授、提问、指令、反馈；“推进环节的话”（接下来我们……）算指令 [2]。

### 二、各类的要求（审稿时逐条对）
| 类别 | 要求 | 常见毛病 |
|---|---|---|
| 导入语 | 有疑问性：抛一个学生想回答的问题，直接连到本课内容 [1] | 铺垫太长，绕半天才到课题 |
| 讲解语 | 短、准、用学生听得懂的词；一次讲一个点，讲完马上接问题或活动 [2] | 讲授占比过高，一讲到底 [2] |
| 提问语 | 一次只问一个问题；问完留出候答时间；问题有指向，学生知道往哪想；对答案“有着有落”，错的要落实 [3][5] | 连发三问；问完马上自己答；问题太大太空 [2][5] |
| 指令语 | 可观察（做什么、怎么做：独立/同桌/小组、出不出声）、有时限（多长时间、什么口令开始和停）、清楚、简短，步骤多就拆开说 [6]；用陈述句下指令，不用“你们能不能……” [7] | 只说“观察一下”“讨论一下”，没说做什么、多久、交什么 [2] |
| 过渡语 | 承上启下，让学生知道刚才学到哪、下面干什么；优质课的指令/过渡贯穿全课，不只在开头 [2] | 换页无话，环节之间断开 |
| 评价语 | 描述性、具体：点出是谁、做对了什么具体行为或想法；不只说“很好”“真棒” [1][8][9]；初中生更适合委婉、不当众夸张的表扬 [8] | 笼统表扬；只判对错不说理由 [9] |
| 结束语 | 简明扼要，回到本课主线 [4] | 新内容塞进结尾 |

### 三、写进 PPT 备注的格式（本仓库约定）
- 用【讲】【问】【做】【过渡】【评价】【预设】标签；标签后写老师可以直接说出口的整句，不写“讲解××”这类提纲。
- 每个【问】后面紧跟【预设】（学生可能怎么答、错了怎么接）。
- 学生活动前的【做】写成完整指令：做什么 + 怎么做 + 多长时间 + 开始/停止口令 + 交什么。
- 学生汇报后至少写一句【评价】，点名具体做法（如“第 3 组把每对线拧开再数，数得最准”）。
- 换环节写【过渡】一句话。

### 四、审核检查表
1. 每页屏幕文字：结论句标题；无断词换行；与教材原文一致；不出现教材外的结论（出现须标“拓展”）。
2. 每个提问：一次一问？有候答？有预设？
3. 每个学生活动：指令五要素齐不齐？
4. 每次学生汇报后：有没有具体评价语？
5. 每次换环节：有没有过渡语？
6. 讲解：能不能再短；有没有学生没学过的术语。
