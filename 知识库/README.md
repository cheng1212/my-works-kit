# 教学知识库

> 原则：**先查库，缺什么才学什么；学完的按规范入库，下次直接用。**

## 目录结构（学科 / 学段 / 版本）

```text
知识库/
├─ README.md            本说明
├─ 索引.md              所有条目一览（先看这里）
├─ 调研规范.md          调研必须遵守的标准
├─ 条目模板.md          新条目照这个格式写
├─ 通用能力/            与学科无关的能力
│  └─ 写法/             教案、说课稿、学案、作业、评价量表、板书怎么写
└─ 学科/
   └─ <学科>/<学段>/
      ├─ 课标.md                     该学段课程标准要点（不分版本）
      └─ <版本>/                     如 人教版2024
         ├─ 教材结构.md              各册单元与课时
         └─ 课时/<册>-<单元>-<课题>.md   单课知识、易错点、课例、主线
```

## 使用流程（制作流程第 1 步）

1. **查库**：打开 `索引.md`，按 学科 → 学段 → 版本 → 课时 找。
2. **判断命中**：
   - 状态“已核验”且未过期 → 直接用，不再调研。
   - 状态“待核验” → 按调研规范补核验后再用。
   - 没有 → 列入“缺口清单”。
3. **只学缺口**：按 `调研规范.md` 调研缺口内容。
4. **入库**：按 `条目模板.md` 写成条目，更新 `索引.md`。
5. **交付时注明**：本课哪些内容来自库、哪些是新学的。

## 维护规则

- 一个知识点只存一处，其他地方引用路径，不复制。
- 教材或课标改版：旧条目标记“已过期”，新版本另建文件夹，不覆盖。
- 每次使用条目时顺手检查：来源链接是否还在、有无新版。发现问题当场修正并更新日期。
- 写法库每做一单就补充一次新发现，越用越准。
