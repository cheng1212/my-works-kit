# 去AI味（教学文案版）：写前契约 → 机扫 → 盲审 → 总闸

给教案、说课稿、逐字稿、学案、作业、评价、反思、PPT 大纲做“去AI化”体检：找出 AI 写作的典型痕迹，给出行号和原句，按 HARD / WARN 分级。

- 移植自 `novel-library-v2`：`程序/工具/禁忌.py`（词面维）、`程序/工具/指纹.py`（结构维）、`库/成文/卡片/写作工艺-AI 稿修订专项.md`（修法），去掉了只适用于小说的项，补了教学文案特有的项。
- 修法见 `知识库/通用能力/写法/去AI味修订.md`。
- 词表和阈值全在 `规则.json`，改规则不用改代码；每条都标了来源（[移植] 原值 / [教学] 新定经验值）。

## 用法

```bash
# 查一个作品文件夹（自动跳过 10-源码、09-逐页预览、审阅档；同名 md/docx 只查 md）
python3 工具/去AI味/去AI味检查.py 06-计算机网络连接-信息科技PPT

# 查单个文件，并存一份报告
python3 工具/去AI味/去AI味检查.py 02-教案/教案.md --报告 02-教案/去AI味报告.md

# 严格模式：WARN 也算不过
python3 工具/去AI味/去AI味检查.py 某作品 --严格
```

只用 Python 标准库，支持 `.md` `.txt` `.docx`。

## 查什么

| 级别 | 项 |
|---|---|
| HARD（不可交付） | 聊天残留（以下是…/希望对你有所帮助）、点破句式、AI 套话（值得注意的是/在…的浪潮中/开启…之旅）、引号体系混用、繁体字残留、docx 里的 Markdown 符号 |
| WARN（人工判） | 教学空话密度、总结腔、系词回避、比喻词密度、空泛表扬（逐字稿）、「不是A而是B」、破折号密度、三并列排比、同头排比、加粗过密、句长太匀、复读片段、中英夹杂 |
| 只报读数 | 句长 CV、半角标点所在行 |

## 豁免

- 以 `>` 开头的引用行（课标、教材原文）不查词面；
- 反引号里的词算“提及”，不算使用；
- 文件名含 质检 / 审核 / 审校 / 审读 / 自审 / 去AI味报告 的整篇只报不判；
- 表格行、标题行、代码块不进结构统计。

## 在创作系统里的位置

- 写前：动笔前读 `知识库/通用能力/写法/去AI味写前契约.md`；`--契约` 打印当前规则里的数，用来核对契约卡有没有跟着改；
- 第 2 步写完教学文案：跑一遍，HARD 清零再进第 3 步；
- 第 9 步质检：对整个作品文件夹再跑一遍，结果写进交付说明。

## 盲审与总闸（移植 v2 盲审.py / 机械闸.py）

| 文件 | 作用 |
|---|---|
| `盲审.py --派单 <文件>` | 出冷读任务书，存到 `<作品>/审核/`；派一个新开、无上下文的子代理，只给任务书和这份文件 |
| `盲审.py --记 <审查单> <文件>` | 校验审查单格式（判定、对象、四小节、语义层六条、FAIL 必须摘原句），归档为 `<文件名>-盲审-<轮>.md`，记下被审文件指纹；上限 3 轮 |
| `闸.py <作品文件夹>` | 01–07、11 号文件夹里每份文案：机扫无 HARD＋最新盲审 PASS/WARN 且指纹对得上 → 过；结果写入 `<作品>/审核/去AI味闸.md` |

为什么要无上下文：写稿的上下文里大纲、要求全在，它看见的每一句都是“应该的”，AI 味天然隐身；只给成稿，审的人才会像听课老师一样被绊住。
